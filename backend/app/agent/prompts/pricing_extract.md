- 일반(Standard) 요금만 사용합니다. Batch, Flex, Priority/Fast, 캐시 쓰기, 긴 컨텍스트 할증 같은 다른 요금은 무시합니다.

- 숫자를 확신할 수 없는 모델은 넣지 않습니다. 설명 없이 JSON 만 출력하세요.
