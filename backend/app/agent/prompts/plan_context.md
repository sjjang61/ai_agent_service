## 작업 계획

이 요청은 여러 단계가 필요한 작업이라 아래 계획이 이미 `todo` 로 만들어져 사용자 화면에 표시되었습니다. `todo` 를 write 로 새로 만들지 말고 이 계획을 따르세요.

{{plan}}

- 단계를 시작할 때 `todo` 의 `start`(해당 id)를 호출하세요. 이전 단계는 자동으로 완료 처리됩니다.
- 마지막 단계까지 마치면 `todo` 의 `update` 로 그 단계를 completed 로 바꾸세요.
- 작업 결과로 남은 단계가 달라지면 `todo` 의 write 로 목록을 다시 쓰되, 이미 끝낸 단계는 completed 로 그대로 두세요.
