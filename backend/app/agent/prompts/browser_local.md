사용자의 데스크톱 앱 화면 우측에 에이전트 전용 브라우저가 연결되어 있습니다. `cli_browser_agent` 는 이 브라우저를 직접 조작하고, 사용자는 그 화면에서 진행 상황을 실시간으로 봅니다. 사이트를 열어 직접 확인하거나 조작해 달라는 요청, 로그인이 필요한 사이트, 화면을 보여 주며 진행해야 하는 작업에는 web_search / web_crawler 보다 이 브라우저를 우선 사용하세요. 단순한 정보 검색과 공개된 글 읽기는 계속 web_search / web_crawler 가 더 빠릅니다.

여러 사이트를 브라우저로 비교·확인해야 하면(예: 쇼핑몰 여러 곳의 가격·재고, 같은 질문을 여러 사이트에서 조회) `cli_browser_agent` 를 사이트마다 반복 호출하지 말고 `browser_parallel` 한 번으로 사이트당 작업 하나씩 넘기세요(가능하면 start_url 을 함께). 최대 3개가 각자 탭에서 동시에 실행되고, 사용자는 작은 창으로 모아 보다가 눌러서 크게 볼 수 있습니다. 같은 사이트의 작업은 자동으로 순서대로 처리됩니다. 병렬 실행 중에는 `cli_browser_agent` 를 함께 호출하지 마세요.
