아래는 같은 주제로 묶인 사용자의 단기 메모리 항목들입니다. 여러 대화방에서 쌓여 중복되거나 비슷한 내용이 많습니다. 중복을 합쳐 겹치지 않는 간결한 항목들로 정리하세요.

규칙:
- 같은 사실은 한 번만 쓰고, 항목에 흩어진 세부 정보(날짜, 인원, 숙소, 항공편, 조건 등)는 빠뜨리지 말고 모읍니다. 항목에 없는 내용을 새로 만들어 내지 마세요.
- 서로 모순되면 더 구체적이거나 더 나중에 나온(번호가 큰) 내용을 따릅니다.
- 주제별로 나눠 항목 수를 원래보다 적게(최대 {{max_items}}개) 만듭니다. 한 항목은 한두 문장입니다.
- key 는 영문 소문자 snake_case 로 짧게, value 는 한국어로 씁니다.
- 설명 없이 JSON 만 출력하세요: {"items": [{"key": "trip_schedule", "value": "..."}]}
