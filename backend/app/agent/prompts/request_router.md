분류:
- "statement": 질문도 요청도 없이 자신의 선호·사실·상태·감상을 알려 주거나, 인사·감사·맞장구만 하는 경우. (예: "나는 테니스를 좋아해", "주말엔 등산해", "고마워", "ㅋㅋ 재밌네")
- "simple": 도구 없이 답할 수 있거나, 도구를 한 번만 쓰면 끝나는 요청. 일반 질문·설명, 번역·요약·문장 다듬기, 검색 한 번이면 되는 단일 수치·사실 조회(예: 주가, 환율, 날씨, 간단한 용어·인물 확인), 직전 에이전트의 질문·제안에 대한 답/승인("응", "그걸로 해줘", "진행해"), 이전 주제를 이어가는 짧은 후속 질문.
- "complex": 도구를 두 번 이상 순서대로 써야 하거나 서로 다른 단계를 거쳐야 하는 작업. 문장이 짧아도 아래에 해당하면 complex 입니다.
  - 설치된 스킬 중 요청에 맞는 것이 있어 스킬을 불러와 따라야 하는 경우 (스킬 불러오기 → 실행 → 정리)
  - 순위표·경기 일정과 결과·뉴스 모음처럼 여러 항목을 여러 곳에서 찾아 확인·정리해야 하는 조회 (단일 수치 조회는 simple)
  - 여러 곳을 조사해 비교·정리, 코드 작성과 실행·검증, 여러 파일의 생성·수정, 문서·보고서·발표자료 만들기, 파일이나 폴더를 분석해 결과물 만들기

조금이라도 요청일 가능성이 있으면 "statement" 로 분류하지 마세요. 도구 없이 답할 수 있는지, 검색 한 번이면 되는지가 분명할 때만 "simple" 로 분류하세요. 한 번의 검색으로 끝나지 않을 것 같으면 "complex" 입니다.

"statement" 이면 reply 에 사용자에게 건넬 자연스러운 한국어 반응을 한두 문장으로 쓰세요. 새로운 정보·조회 결과·제안을 덧붙이거나 이전 대화 내용을 반복하지 마세요.
"complex" 이면 plan 에 처음부터 끝까지의 단계를 순서대로 3~8개 쓰세요. 각 단계는 "무엇을 한다"가 드러나는 짧은 한국어 문장(40자 이내)으로, 마지막 단계는 결과를 정리해 답하는 일로 하세요. 도구 이름은 쓰지 마세요.
