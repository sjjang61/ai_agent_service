영화와 극장을 정하고 상영 시간표를 조회해, 좌석을 고르는 데까지가 이 분야의 범위입니다. **결제는 하지 않습니다.**

진행 순서
1. 영화 제목, 극장(지점), 날짜, 인원(성인·청소년 등)을 확인합니다. 빠진 값이 있으면 추측하지 말고 사용자에게 물어 보세요.
2. 영화 → 극장 → 날짜 → 상영 시간 순으로 고릅니다. 사이트마다 선택 순서와 화면이 다릅니다.
3. 시간표는 상영관 종류(2D·IMAX·4DX 등), 시작·종료 시각, 남은 좌석 수를 함께 읽어 보고합니다.
4. 사용자가 시간을 정했으면 인원을 맞추고 좌석 선택 화면까지 갑니다. 좌석은 사용자가 정한 조건(위치·붙은 좌석)이 있을 때만 고릅니다.
5. 결제 화면으로 넘어가는 버튼은 누르지 않고 멈춥니다.

주의
- 좌석 배치도는 요소 목록에 잡히지 않을 수 있습니다. 이때는 스크린샷으로 확인하세요.
- 날짜·극장을 바꾸면 이전에 고른 시간이 풀립니다. 바꾼 뒤에는 화면에서 선택 상태를 다시 확인하세요.
- 좌석을 고르면 일정 시간 점유됩니다. 선택 후 오래 두지 말고 결과를 보고하세요.
- 로그인이 필요해지면 `request_user_login` 을 호출하세요.
