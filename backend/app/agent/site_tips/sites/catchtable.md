홈 검색창에 바로 입력하고 Enter 를 누르는 방식은 검색 결과로 이동하지 않는다. 검색 아이콘으로 `/ct/search/total` 화면에 먼저 들어가 검색한다.
검색 결과는 지도형 화면이며 지도 중심·반경·선택 매장·시트 높이 등 부가 파라미터가 주소에 자동으로 붙는다. `serviceType=INTEGRATION`, `keyword`, `keywordSearch` 만 남긴 축약 주소로도 열린다. 사이트가 지역·음식·거리 필터를 자동으로 덧붙이므로 이 값은 재사용하지 않는다.
홈 첫 방문 시 '닫기' 팝업이 뜬다.
검색 결과 화면 상단의 '날짜 인원' 버튼은 에이전트가 눌렀을 때 주소가 `app.catchtable.co.kr/?…` 로 바뀌며 홈으로 이동한 것처럼 보였고(요소가 수십 개 늘어남), 시트를 읽지 못했다. 예약 시트(달력·인원·시간)는 매장 상세 페이지에서 예약 버튼을 눌러 여는 화면으로 보이며(사용자 제공 스크린샷의 시트 뒤에 매장 상세 헤더가 보임) 이 목록 컨트롤은 쓰지 않는다. 시트 상단에 프로모션 배너(예약하기 버튼 포함)가 있을 수 있으며 누르지 않는다.
