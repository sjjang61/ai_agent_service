예매 화면(`/NLCHS/Ticketing`)은 주소로 직접 이동해도 영화관·영화·날짜 영역이 한 화면에 표시된다 (3단 구성: 영화관 / 영화 선택 / 날짜와 시간표).
예매 첫 화면에는 `01 상영시간 > 02 인원/좌석 > 03 결제 > 04 결제완료` 단계 표시가 있다. 시간표는 01 상영시간 단계에서 읽는다.
극장·영화를 아직 고르지 않으면 시간표 영역에 '현재 선택하신 날짜의 상영 시간표를 준비하고 있습니다.' 안내가 보인다.
롯데시네마의 서울 극장 목록에는 '강남'이 없다 (가산디지털, 가양, 강동, 건대입구, 김포공항, 노원, 도곡, … 월드타워 등). 사용자가 말한 극장이 목록에 없으면 비슷한 지점을 임의로 고르지 말고 목록에 없다고 보고한다.
예매 화면에서 '팝업 닫기' 버튼이 여러 번 나타날 수 있고 좌우에 광고 배너가 있다. 팝업은 닫고 진행하며, 안 닫히면 Escape 키를 쓴다.
극장·영화·날짜를 선택한 뒤에는 화면을 다시 읽어 선택 상태와 시간표를 확인한다.
극장 → 영화 → 날짜 순으로 선택해도 시간표가 정상으로 표시된다 (선택 순서는 영화 → 극장 → 날짜여도 무관한 것으로 보이나 이 순서로 확인했다).
초기 화면의 '팝업 닫기' 버튼 2개(예매 내용 확인 팝업, 레이어 팝업)는 화면에 보이지 않는 숨은 팝업의 것이라 눌러도 아무 변화가 없다. 누르거나 Escape 를 반복하지 말고 바로 영화관 영역에서 시작한다.
예매 화면은 영화관·영화·날짜 3개 영역이 각각 안쪽 스크롤을 가진다. 지역(서울) → 극장(월드타워 등) → 영화 → 날짜 순으로 누르고, 한 번 누를 때마다 화면을 다시 읽어 다음 요소를 찾는다 (극장을 고르면 영화·날짜 목록이 다시 그려진다). 같은 이름의 극장이 둘로 보이면(1/2, 2/2) 순번으로 구분한다.
일괄(batch)로 여러 단계를 묶지 말고 하나씩 누른다.
