# 사이트별 요령 (브라우저 에이전트 리소스)

사이트마다 달라지는 사용법(검색·정렬 주소, 알려진 함정)을 프롬프트가 아니라 **데이터**로 둔다. 사이트 UI가 바뀌면 그 파일만 고친다.
`app/agent/site_tips.py` 가 읽어서, 작업에 해당하는 사이트의 요령만 브라우저 에이전트에게 준다.

- **시작할 때**: 작업의 시작 URL·작업 문장에 나온 주소·사이트 이름에 맞는 파일만 지침 끝에 붙인다.
- **이동할 때**: 에이전트가 처음 방문하는 도메인에 맞는 요령이 있으면, 그 이동 결과 끝에 한 번만 덧붙인다 (시작할 때 놓친 사이트, 링크로 넘어간 사이트).

## 파일 형식

```
---
name: 다나와                # 필수. 화면·안내에 쓰는 이름
domains: danawa.com         # 필수. 쉼표로 여러 개. 하위 도메인(search.danawa.com)도 맞는다
aliases: 다나와              # 선택. 작업 문장에서 이 단어가 나오면 시작할 때 붙인다 ('다음' 처럼 흔한 단어는 피한다)
verified: 2026-11-09        # 필수. 이 요령을 마지막으로 직접 확인한 날짜 (낡은 요령 구분용)
---
본문 (에이전트에게 그대로 전달된다. 주소 템플릿은 `검색어` 자리표시자를 쓴다)
```

- 확인한 것만 적는다. 추측·일반론은 프롬프트(`prompts/browser_agent.md`)에 둔다.
- 새 파일을 추가하면 `tests/unit/test_site_tips.py` 가 형식(필수 항목, 날짜, 도메인 중복)을 검사한다.
